# Legal and Intellectual Property

This index separates legal concerns that must not be conflated. It is informational and not legal advice.

1. **Project software licensing:** [LICENSE](../../LICENSE) contains the controlling FSL-1.1-ALv2 terms for protected versions and the Apache-2.0 Future License grant.
2. **Contribution licensing:** [Contributor License Agreement](../../CONTRIBUTOR_LICENSE_AGREEMENT.md) preserves contributor ownership while granting the Project Owner the rights required to distribute, sublicense, relicense, and dual-license accepted contributions.
3. **Commercial licensing and services:** [COMMERCIAL.md](../../COMMERCIAL.md) explains optional commercial licenses and services without changing the public license.
4. **Trademarks:** [TRADEMARKS.md](../../TRADEMARKS.md) separates software rights from project and third-party branding.
5. **Third-party software:** [Third-party licensing](third-party-licensing.md) tracks dependency, provider, redistribution, and provenance obligations independently from the Project's license.
6. **Third-party services and APIs:** Provider terms, data-use rules, and trademark requirements require integration-specific review even when software dependencies are compatible.
7. **Security and privacy:** [SECURITY.md](../../SECURITY.md) governs vulnerability reporting; [security and privacy requirements](../security/README.md) describe the agreed data-handling baseline.

## Current Contribution Gate

External issues, discussions, design proposals, and pull requests for discussion are welcome. External code must not be merged until the contributor has accepted the applicable CLA through a durable, auditable mechanism and provenance checks have passed. A CLA file by itself is not sufficient.
