# Support

`universal-data-mcp-worker` is a small maintainer-led project. Support is best effort and no response-time SLA is offered.

## Bugs, features and integrations

Use [GitHub Issues](https://github.com/marceloomiqueles/universal-data-mcp-worker/issues) and select the appropriate template. Search for duplicates first and never share tokens, credentials, personal data, complete Garmin payloads or unredacted logs.

Feature and integration requests should explain the real problem and evidence before proposing abstractions.

## Questions

GitHub Discussions is currently disabled and there is no separate chat. For a concrete question that blocks use or contribution, open a regular issue with sanitized context. Discussions can be reconsidered if question volume justifies it.

## Vulnerabilities

Do not use public issues. Follow [SECURITY.md](SECURITY.md) and use GitHub Private Vulnerability Reporting.

## Installation, commercial support and sponsorship

There is no maintainer-provided installation or commercial support channel today. The software must remain fully functional without paid support; paid assistance, if introduced, will be optional.

Sponsorship is not configured. No `.github/FUNDING.yml` is included until the maintainer supplies a real GitHub Sponsors username or funding URL. Sponsorship will not unlock features or change access to the software.
